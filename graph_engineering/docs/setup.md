# Graph Engineering - Environment Setup

## Requirements
- Python 3.10+
- Neo4j Desktop
- VS Code
- Git

## Python Environment

Create a virtual environment:

python -m venv .venv

Activate on Windows:

.venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

## Database

Neo4j will be used to store supply-chain
entities and their relationships.
